# Spinzy

> A full-screen promotional prize-wheel experience for FlexCar events — guests spin for weighted prizes on a branded canvas UI; operators tune the catalog without touching code.

**Role:** Designer & front-end
**Type:** Marketing experience
**Stack:** TypeScript, Vite, Konva, Web Audio API
**Links:** [GitHub](https://github.com/patriarxis/spinzy)

Booth-ready activation: probability-weighted outcomes, win / try-again results with motion and sound, and an on-device settings panel for prizes and odds.
